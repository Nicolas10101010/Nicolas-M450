1. Welche Formen von Tests kennen Sie aus der Informatik?
- Ich kenne Unit-Tests, Integrations-Tests und End-to-End Tests, Unit-Tests testen einen spezifischen Teil eines Codes (hauptsächlich einzelne Methoden) dafür benutze ich meistens JUnit. Integrations-Tests testen die Verbindung zwischen z.B. Frontend und Backend und dafür habe ich meistens Postman verwendet oder Bruno verwendet. Bei den E2E-Tests wird die ganze Applikation getestet, dafür habe ich Cypress verwendet.
